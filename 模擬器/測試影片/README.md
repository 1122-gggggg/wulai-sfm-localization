# 測試影片資產

此目錄保存離線 replay 與回歸測試使用的影片，不納入 Git。影片是輸入資產，不是
`outputs/` 產物。

規則：

- 原始影片保留原檔名；轉碼衍生檔在名稱加解析度或用途，例如 `_720p`、`_anafi5m`。
- 正式品質 gate 必須另外記錄 SHA-256、宣告幀數、可解碼幀數與已知例外。
- 不用重新編碼的 30 FPS 重複幀衡量定位 FPS；replay 保留來源原生 FPS。
- 影片不得放進場域 `maps/` 或 `bundles/`，也不得放入 `.venv/`。
- 大檔移往外部儲存前，先確認所有 benchmark／receipt 是否仍能由 digest 找回來源。

P119 如要作為預設模擬影片，請將 `P1190119.MP4` 匯入本目錄；啟動器會根據固定
SHA-256 與 2935 宣告／2934 可解碼的已知例外進行檢查。也可匯入任意單一模擬影片，或用 `VIDEO=` 明確指定多部影片之一。
